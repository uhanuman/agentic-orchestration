# 04. Semantic Requirement Ambiguity Evaluator (`EVAL-AMBIGUITY-SEMANTIC`)

## 1. Objective
Evaluate whether the requirement text and acceptance criteria contain untestable, vague, subjective, or contradictory statements.

## 2. Evaluation Rubric
- **0.00 - 0.05**: Crystal clear, measurable quantitative thresholds, explicit error paths.
- **0.06 - 0.15**: Minor ambiguities, easily clarified with standard defaults.
- **0.16 - 0.40**: Noticeable subjective adjectives ("fast", "user-friendly") without numeric boundaries.
- **> 0.40**: Grossly underspecified, contradictory requirements.

## 3. Threshold Rule
Ambiguity score MUST be $\le 0.15$ to pass the Requirement Quality Gate (`GATE-REQ-001`).
