# 02. Deterministic Referential & Traceability Validator (`EVAL-REFERENTIAL-001` / `EVAL-TRACEABILITY-001`)

## 1. Objective
Ensure unbroken bidirectional lineage across the Quality Engineering DAG:
`REQ -> AC -> SCN -> TC -> AUT -> TEX -> TRS -> REL`.

## 2. Referential Invariants
1. `AcceptanceCriteriaArtifact.requirementId` MUST point to existing `REQ`.
2. `ScenarioArtifact.requirementId` MUST point to existing `REQ`.
3. `ScenarioArtifact.acceptanceCriteriaId` MUST point to existing `AC`.
4. `TestCaseArtifact.scenarioId` MUST point to existing `SCN`.
5. `TestCaseArtifact.requirementId` MUST point to existing `REQ`.
6. `AutomationBlueprintArtifact.testCaseId` MUST point to existing `TC`.

## 3. Evaluation Logic
- Query context store for all referenced parent artifacts.
- Return `score = 1.0` if 100% of foreign keys exist.
- Return `score = 0.0` and list orphaned records if foreign key verification fails.
