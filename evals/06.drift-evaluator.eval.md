# 06. Semantic Specification Drift & Hallucination Evaluator (`EVAL-DRIFT-SEMANTIC`)

## 1. Objective
Detect any hallucinations, unauthorized assumptions, or ungrounded assertions introduced during scenario synthesis, test case design, or automation blueprint generation.

## 2. Evaluation Rubric
- **0.00 - 0.05**: Purely grounded in requirement acceptance criteria and domain context.
- **0.06 - 0.10**: Minor plausible assumptions (e.g. standard HTTP status codes).
- **0.11 - 0.30**: Fabricated business logic, unrequested constraints, invented endpoints.
- **> 0.30**: Critical hallucination: tests asserting contradictory or completely fabricated behaviors.

## 3. Fast-Fail Threshold
Hallucination Index MUST be $\le 0.10$ to pass the Release Gate (`GATE-VAL-001`).
Zero waiver bypass permitted for Critical Hallucination failures.
